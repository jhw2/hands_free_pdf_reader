# Hands Free PDF Reader

입모양으로 PDF 페이지를 넘길 수 있는 브라우저 기반 뷰어입니다.

## 실행

1. `npm install`
2. `npm run dev`
3. 브라우저에서 `http://localhost:3000` 접속

## 사용 방법

1. **PDF 불러오기**로 PDF를 엽니다.
2. **모션 감지 켜기**를 누르고 카메라 접근을 허용합니다. 별도 보정은 필요하지 않습니다.
3. **다음 페이지:** 입을 설정한 시간(기본 0.5초) 동안 벌려 유지합니다. 사용법의 설정값은 브라우저에 저장되어 다음 접속에도 유지됩니다.
4. **이전 페이지:** 입을 빠르게 벌렸다 닫고 바로 다시 벌립니다. 첫 벌림은 0.06초 이상, 다음 페이지 넘김 시간 미만으로 하고, 닫은 뒤 0.6초 안에 두 번째 벌림이 감지되어야 합니다. 두 번째 벌림이 감지되면 즉시 넘어가므로 0.6초를 기다릴 필요는 없습니다.
5. 페이지 이동 후 입을 닫으면 다음 동작을 받을 수 있습니다. 연속 이동 방지를 위해 이동 간 1.2초 간격이 적용됩니다.
6. 터치나 마우스로 PDF를 왼쪽으로 밀면 다음 페이지로, 오른쪽으로 밀면 이전 페이지로 이동할 수 있습니다.

입을 계속 벌리고 있어도 페이지는 한 번만 이동합니다. 화면의 이전·다음 버튼으로도 이동할 수 있습니다.

## 기능

- `pdf.js` 기반 PDF 렌더링
- `MediaPipe FaceMesh` 기반 입모양 감지
- PDF 및 마지막 읽은 페이지 저장
- 전체보기와 수동 페이지 이동
